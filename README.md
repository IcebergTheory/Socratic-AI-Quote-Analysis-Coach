# Socratic AI Quote Analysis Coach

This folder contains the static GitHub Pages version of the website.

## Publish at https://icebergtheory.github.io/Socratic-AI-Quote-Analysis-Coach/

1. Sign in to the `IcebergTheory` GitHub account.
2. Create a new **public** repository named exactly `Socratic-AI-Quote-Analysis-Coach`.
3. Unzip the package and upload **all files and folders inside this folder** to the repository root. Include `.nojekyll` and the `_next` folder.
4. Commit the uploaded files to the `main` branch.
5. Open **Settings → Pages** in the repository.
6. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then save.
7. After GitHub finishes publishing, visit `https://icebergtheory.github.io/Socratic-AI-Quote-Analysis-Coach/`.

The package contains no Git history, personal name, ChatGPT Sites address, or account-specific hosting configuration.
